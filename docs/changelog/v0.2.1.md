# v0.2.1

Patch release with fixes from the real-board trial (card #9, workspace notes `04-trial-catches.md`).

## Fixed

- **List order matches the browser.** Lists without a `sort` value (new lists, made through the API or in the
  browser, until Wekan renumbers them) were shown last; Wekan's browser shows them first. `wekan board` now shows
  them first too, in export order, and marks them `(no position yet: drag it into place in the browser)`. `--json`
  has `"positioned": false` on such a list. Lists with a `sort` value are unchanged.
- **`new-card` help said "at the top of a list".** Wekan puts a new card at the bottom (`sort` = number of cards
  already in the list); the command did that all along. The help text and the v0.2.0 changelog now say "bottom".

## Tests

- The fake Wekan now places cards like Wekan does: a new card at the bottom, a moved card at the top. Before, it put
  new cards at the top, which is why the tests agreed with the wrong help text.
- The fixture's lists have `sort` values, as on real boards; tests that need a list without one set it to `null`.
- New tests: lists without `sort` first and marked (text and JSON), checklists without `sort` still last, new card
  at the bottom, moved card at the top.
