# v0.2.0

Write commands, built in two PRs: A (PR #3, everyday changes) and B (`new-card`, `label`, `delete-item`, live
tests).

v0.1.0 was tagged and uploaded to TestPyPI on 2026-11-10.

## Added (PR A)

- `wekan add-item N "text" [--done] [--checklist NAME] [--numbered]`: adds to the card's only checklist, the named one,
  or a new "Steps" checklist. Several checklists and no `--checklist` is refused (exit 7) instead of guessed.
  `--numbered` puts the next free `(N)` in front. Warns about titles like "1. Step", which Wekan renders as a numbered
  list.
- `wekan tick N MATCH... [--undo] [--all]`: a bare number `2` matches the item numbered `(2)`, other text part of the
  title (case-insensitive), across all checklists. A match that fits several items lists them and exits 4, unless
  `--all`. Items already in the wanted state are reported as `unchanged` and not sent.
- `wekan move N LIST [--from LIST] [--swimlane S] [--over-wip]`: a full hard WIP limit refuses the move (exit 7) unless
  `--over-wip`; a full soft limit warns. `--from` refuses when the card is elsewhere. A card already in the list is
  `unchanged`.
- `wekan describe N --file PATH|-`: replaces the description (from a file or stdin). An empty text clears it.
- Every change is read back from a fresh export and printed as `from → to (verified)`; if the read-back doesn't show
  it, exit 8. `--json` prints the change as an object (a list for `tick`).
- `--credentials` is accepted after the command too (`wekan boards --credentials F`); the command's value wins over
  the global one.
- `WekanClient.post/put/delete` (JSON bodies), list/checklist/item matching in `resolve.py`, and `actions.py` with one
  function per write command, free of typer so it can be tested on its own.
- Fake Wekan: write routes that keep state, a `drop_writes` switch to test the read-back check, and two quirks: a card
  `PUT` through the wrong list answers an empty 200, and an empty description answers 404.

## Added (PR B)

- `wekan new-card LIST "title" [--file PATH|-] [--labels a,b] [--swimlane S] [--force] [--over-wip]`: created at the
  top of the list, in the list's swimlane, with the logged-in account as author; prints the new card's number. A card
  with the same title (not archived) refuses it (exit 7) unless `--force`. Keeps to WIP limits like `move`. Labels
  are set with a second request, because Wekan ignores them on a create.
- `wekan label N LABEL [--remove]`: by name, or colour for a label without a name. The card's other labels stay
  (Wekan replaces the whole set). Already on (or off) is `unchanged`.
- `wekan delete-item N MATCH --yes`: deletes exactly one item (a hard delete in Wekan). Without `--yes` nothing is
  sent; the refusal names the item (exit 7).
- Live tests (`tests/test_live.py`, `pytest -m live` with `WEKAN_LIVE_BOARD`): every write command once on a
  throwaway board; refuses a board whose title doesn't contain "test". Creates one card per run, deletes its items
  afterwards, and leaves the card to archive by hand. Uses the real credentials and token cache.
- Fake Wekan: card create (ignores `labelIds`, like Wekan) and hard item delete.
