# v0.1.0 (unreleased)

## Added

- Project skeleton: `pyproject.toml` (hatchling, `wekan` entry point, httpx + typer, dev extras pytest/black/ruff),
  `src/` layout, `python -m wekan_cli`.
- `wekan --version` and `wekan version`. Help output is plain text (no rich boxes), so agents read it cheaply.
- Error classes with distinct exit codes (`errors.py`); `main()` prints one stderr line per error, and hides the
  message and traceback of unexpected errors (they could hold a secret) unless `WEKAN_DEBUG=1`.
- Test harness: a fake Wekan on `httpx.MockTransport` with the real API's quirks, a made-up demo board fixture, and an
  isolated `HOME` for every test.
- Docs: README, CLAUDE.md, `docs/claude/` (architecture, conventions, testing).
